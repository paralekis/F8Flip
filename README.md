F8Flip 🪶

Маленька, блискавично швидка утиліта для Windows, яка виправляє неправильно набраний текст 
(наприклад ghbdtn $\rightarrow$ привіт).

Як користуватися:
  1. Завантажте файл F8Flip.exe з розділу Releases (справа).
  2. Запустіть його. При першому запуску програма запропонує обрати зручну гарячу клавішу (за замовчуванням F8).
  3. Напишіть текст (будь де), зрозумійте що помилилися розкладкою, натисніть F8 - текст миттєво виправиться!
  4. Є можливість змінювати транслітерацію обраного тексту

Щоб викликати меню налаштувань повторно, натисніть Ctrl + Win + F8.
